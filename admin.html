KALAMATATODAY Διαχείριση

Σύνδεση

Βάλτε το κλειδί (token) του GitHub. Αποθηκεύεται μόνο σε αυτόν τον browser.

Πώς φτιάχνω token;
  1. Ανοίξτε το GitHub → Fine-grained token.
  2. Token name: Kalamata Today admin. Expiration: όσο θέλετε (π.χ. 1 χρόνο).
  3. Repository access: Only select repositories → Kalamata-Today.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Πατήστε Generate token, αντιγράψτε το και βάλτε το εδώ.
