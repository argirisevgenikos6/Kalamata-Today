Ρύθμιση κωδικού

Βάλτε μία φορά το κλειδί (token) του GitHub και διαλέξτε έναν κωδικό. Από εκεί και πέρα θα μπαίνετε μόνο με τον κωδικό, από οποιαδήποτε συσκευή.

← Πίσω στη σύνδεση με κωδικό

Πώς φτιάχνω token;
  1. Ανοίξτε το GitHub → Fine-grained token.
  2. Token name: Kalamata Today admin. Expiration: όσο θέλετε (π.χ. 1 χρόνο).
  3. Repository access: Only select repositories → Kalamata-Today.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Πατήστε Generate token, αντιγράψτε το και βάλτε το εδώ.

Πρωτοσέλιδο — έτσι φαίνεται τώρα η κορυφή του site

Για να αλλάξετε ποιο θέμα μπαίνει πού, διαλέξτε «Θέση» στη λίστα ειδήσεων πιο κάτω. Οι θέσεις που μένουν «αυτόματα» παίρνουν τις πιο πρόσφατες ειδήσεις.
