# Kalamata Today

Ειδησεογραφική ιστοσελίδα για την Καλαμάτα και τη Μεσσηνία, με μαύρο και πορτοκαλί θέμα.

## Αρχεία

- `index.html`: η δομή της σελίδας
- `style.css`: το θέμα (μαύρο/πορτοκαλί) και το responsive layout
- `script.js`: η αναζήτηση, τα φίλτρα κατηγοριών, το ticker και ο καιρός
- `news.json`: οι ειδήσεις και τα έκτακτα του ticker
- `admin.html`, `admin.js`, `admin.css`: η σελίδα διαχείρισης

## Διαχείριση ειδήσεων

Ανοίξτε το `https://argirisevgenikos6.github.io/Kalamata-Today/admin.html`.
Από εκεί προσθέτετε, διορθώνετε και διαγράφετε ειδήσεις (με φωτογραφία) και αλλάζετε τα έκτακτα.
Κάθε αλλαγή αποθηκεύεται στο `news.json` του repo και εμφανίζεται στο site σε περίπου 1 λεπτό.

**Σύνδεση με κωδικό.** Την πρώτη φορά η σελίδα ζητά ένα GitHub token (οδηγίες μέσα στη σελίδα:
Fine-grained token → μόνο το repo **Kalamata-Today** → **Contents: Read and write**) και έναν κωδικό που διαλέγετε.
Το token αποθηκεύεται κρυπτογραφημένο με τον κωδικό στο `admin-key.json`, οπότε μετά μπαίνετε μόνο με τον κωδικό,
από οποιαδήποτε συσκευή. Διαλέξτε δυνατό κωδικό (10+ χαρακτήρες), γιατί το αρχείο είναι δημόσιο.
Για αλλαγή κωδικού ή νέο token: «Ξέχασα τον κωδικό / Αλλαγή κωδικού» στη σελίδα σύνδεσης.

**Σειρά ειδήσεων.** Στο site οι ειδήσεις μπαίνουν με τη νεότερη πρώτη. Το πρωτοσέλιδο (τα 3 θέματα στην κορυφή)
γεμίζει αυτόματα με τις 3 πιο πρόσφατες, εκτός αν διαλέξετε «Θέση» 1, 2 ή 3 για κάποια είδηση στη σελίδα admin.

Οι ειδήσεις που υπάρχουν τώρα είναι **δείγματα** — διαγράψτε τις από τη σελίδα admin όταν βάλετε τις δικές σας.
